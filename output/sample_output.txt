##############################################################################
#             SECTION 1 : ERROR CONTROL  (Hamming SECDED codes)              #
##############################################################################
Hamming codes add parity bits so the receiver can CORRECT a single-bit
error and DETECT a double-bit error entirely on its own. Below we encode
one byte, then show all three outcomes on its coded form.

  Original data byte : 'A' = 0x41 = 01000001
  Hamming-coded form : cc69  (2 bytes = two 8-bit SECDED codewords)

  (a) No error      -> decoded 0x41 'A'  status=NO_ERROR
  (b) 1 bit flipped -> decoded 0x41 'A'  status=CORRECTED   <- repaired automatically, no retransmit
  (c) 2 bits flipped-> status=DOUBLE_ERROR   <- detected, so Go-Back-N will retransmit this frame

==============================================================================
 CSMA/CA  --  multiple access with collision avoidance
==============================================================================
 Stations contending : A, B, C
 Access point (AP)   : 02:00:00:00:00:AA
 RTS/CTS handshake   : ON
 CWmin / CWmax       : 4 / 64
------------------------------------------------------------------------------

 All stations sense the medium IDLE, wait DIFS (2 slots), then pick a random backoff in [0, 3]:
   A: backoff = 1
   B: backoff = 3
   C: backoff = 1

 Counting down (one idle slot = -1 on every pending backoff;
 the first to reach 0 transmits; ties collide):
    slot   2: idle, count down    [A=1  B=3  C=1]
    slot   3: !!! COLLISION !!! A, C transmitted in the SAME slot
            A: no ACK -> binary exponential backoff, CW 4 -> 8, new random backoff = 5
            C: no ACK -> binary exponential backoff, CW 4 -> 8, new random backoff = 4
            medium wasted for 2 slots.
    slot   7: idle, count down    [A=5  B=2  C=4]
    slot   8: idle, count down    [A=4  B=1  C=3]
    slot   9: *** B wins the medium (backoff reached 0) ***
            RTS  B -> AP   : 'may I send?'  (all others set NAV and stay quiet)
            CTS  AP -> B   : 'go ahead'  (after SIFS)
            DATA B -> AP   : sending its frame
            ACK  AP -> B   : received OK  (after SIFS)
            medium BUSY for 3 slots; other stations FREEZE their backoff counters.
    slot  14: idle, count down    [A=3  C=2]
    slot  15: idle, count down    [A=2  C=1]
    slot  16: *** C wins the medium (backoff reached 0) ***
            RTS  C -> AP   : 'may I send?'  (all others set NAV and stay quiet)
            CTS  AP -> C   : 'go ahead'  (after SIFS)
            DATA C -> AP   : sending its frame
            ACK  AP -> C   : received OK  (after SIFS)
            medium BUSY for 3 slots; other stations FREEZE their backoff counters.
    slot  21: idle, count down    [A=1]
    slot  22: *** A wins the medium (backoff reached 0) ***
            RTS  A -> AP   : 'may I send?'  (all others set NAV and stay quiet)
            CTS  AP -> A   : 'go ahead'  (after SIFS)
            DATA A -> AP   : sending its frame
            ACK  AP -> A   : received OK  (after SIFS)
            medium BUSY for 3 slots; other stations FREEZE their backoff counters.
